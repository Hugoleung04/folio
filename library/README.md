# library/

Put PDF files here. Folio **Sync** reads this folder.

Example:

```
library/week1.pdf
library.json   (in the repo root, not inside this folder)
```

Grok can add PDFs to this folder when you drop a file in chat.
Then on your computer open Folio and click **同步 / Sync**.

To **replace** an existing file, keep the same name:

```
library/week1.pdf   ← upload again with this exact name
```

Folio Sync then overwrites the old copy on the device.
